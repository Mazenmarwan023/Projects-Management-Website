# 🗂️ Projects Management Website

A React-based project management application that allows users to create and organize multiple projects, each with its own tasks, descriptions, and due dates.

## 🚀 Features

- **Create Projects**  
  Add new projects by specifying a title, description, and due date.

- **Project Sidebar Navigation**  
  View a list of all your created projects in a convenient sidebar. Selecting a project displays its details.

- **Project Details View**  
  When a project is selected from the sidebar, its title, description, and due date are shown next to it in the main view.

- **Task Management**  
  Add and manage a list of tasks specific to each project.

- **Dynamic Interface**  
  Each project maintains its own tasks and data separately, allowing organized and efficient project handling.

## Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/Mazenmarwan023/Projects-Management-Website.git
    ```

2. Navigate to the project directory:

    ```bash
    cd Projects-Management-Website
    ```

3. Install the dependencies:

    ```bash
    npm install
    ```

4. Run the development server:

    ```bash
    npm run dev
    ```
    
5.Vite will provide a local server URL, typically:http://localhost:5173.
